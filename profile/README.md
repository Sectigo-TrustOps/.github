# Sectigo TrustOps

TrustOps is an open-source certificate and PKI operations portfolio built for
evidence-first discovery, safe automation, and integration with Sectigo
Certificate Manager when an enterprise management plane is required.

## Start here

- [Documentation and runnable browser labs](https://sectigo-trustops.github.io/docs/)
- [Discovery engine](https://github.com/Sectigo-TrustOps/trustops)
- [Deterministic service mocks](https://github.com/Sectigo-TrustOps/cloudmock)
- [OpenTofu modules](https://github.com/Sectigo-TrustOps/opentofu)
- [Automation and platform integrations](https://github.com/Sectigo-TrustOps/integrations)
- SDKs for [Go](https://github.com/Sectigo-TrustOps/sdk-go), [Python](https://github.com/Sectigo-TrustOps/sdk-python), [Java](https://github.com/Sectigo-TrustOps/sdk-java), and [.NET](https://github.com/Sectigo-TrustOps/sdk-dotnet)

## Engineering contract

- Empty and unscanned estates are different states.
- Partial evidence remains visible and blocks unsafe conclusions.
- Mocks and no-account labs are part of the product contract.
- Credentials, private keys, and sensitive source material stay outside
  durable evidence, workflow exports, and infrastructure state.
- A capability is not complete until runtime, mocks, APIs, SDKs, OpenTofu,
  automation, docs, samples, and agent guidance agree.

Use the [delivery-readiness scorecard](https://sectigo-trustops.github.io/docs/reference/delivery-readiness/)
to inspect machine-checked cross-repository evidence.
