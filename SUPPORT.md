# Support

- Use the target repository's issue forms for reproducible bugs, feature
  proposals, and documentation problems.
- Use the [documentation portal](https://sectigo-trustops.github.io/docs/) for
  setup, task guides, browser labs, API contracts, and release status.
- Use the private reporting channel in [SECURITY.md](SECURITY.md) for security
  issues, credentials, private keys, sensitive topology, or abuse paths.

Public issues are not an appropriate support channel for customer account
details or production secrets.
